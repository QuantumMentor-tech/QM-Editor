# QM EDITOR — SUPPORTED LANGUAGES REFERENCE

**Version:** 1.0.0  
**Status:** Approved Reference Specification  
**Last Updated:** October 10, 2026

## SUPPORTED LANGUAGE REGISTRY TABLE

| Language ID | Display Name | Recognized Extensions | Special Filenames / Aliases | Syntax Highlighting |
| :--- | :--- | :--- | :--- | :--- |
| `plaintext` | Plain Text | `.txt`, `.text` | Default fallback | Supported |
| `typescript` | TypeScript | `.ts`, `.tsx` | `tsconfig.json`, `ts`, `tsx` | Supported |
| `javascript` | JavaScript | `.js`, `.jsx`, `.mjs`, `.cjs` | `package.json`, `js`, `jsx` | Supported |
| `json` | JSON | `.json`, `.jsonc` | `.eslintrc`, `.prettierrc` | Supported |
| `markdown` | Markdown | `.md`, `.markdown` | `README.md`, `CHANGELOG.md` | Supported |
| `html` | HTML | `.html`, `.htm` | `index.html` | Supported |
| `css` | CSS | `.css` | `style.css` | Supported |
| `python` | Python | `.py`, `.pyw` | `requirements.txt` | Supported |
| `cpp` | C++ / C | `.cpp`, `.c`, `.h`, `.hpp` | `c`, `cpp` | Supported |
| `rust` | Rust | `.rs` | `Cargo.toml` | Supported |
| `sql` | SQL | `.sql` | `queries.sql` | Supported |
| `shell` | Shell Script | `.sh`, `.bash`, `.zsh` | `Dockerfile`, `Makefile`, `.gitignore`, `.env` | Supported |
| `xml` | XML / SVG | `.xml`, `.svg` | `pom.xml`, `manifest.xml` | Supported |
| `yaml` | YAML | `.yaml`, `.yml` | `.docker-compose.yml` | Supported |

---

> [!NOTE]
> QM Editor language identification governs syntax presentation and theme styling. Language intelligence features (Language Server Protocol, IntelliSense, Semantic Diagnostics, Formatters) belong to future dedicated steps.
